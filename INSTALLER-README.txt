WEB2APK INSTALLER EDITION

1) Run BUILD-WINDOWS-EXE.bat
   Creates: dist\Web2APK.exe

2) Install Inno Setup 6 on the computer used to compile the installer.

3) Run BUILD-INSTALLER.bat
   Creates: installer\Web2APK-Setup-v1.0.1.exe

The setup installs Web2APK as normal Windows software with your supplied icon,
Start Menu shortcut, optional Desktop shortcut, Installed Apps entry and uninstaller.

Node.js and a Java JDK are still required on a machine that uses Web2APK to compile Android APKs.
